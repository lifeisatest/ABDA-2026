Deploying on GitHub Pages for ABDA 2026

Step-by-step instructions to launch this static website for free

  1. Push your code and index.html to your GitHub repository (e.g., abda2026-eposters).
  2. Go to repository Settings → Pages.
  3. Under Branch, select main and keep the folder as /(root).
  4. Click Save. Your portal will be published online in 1–2 minutes!

Add & Import Submitted E-Posters

Easily update poster data or paste custom JSON metadata

Option A: Edit Directly in `index.html`

Open index.html in your editor. Look for the variable RAW_SUBMITTED_POSTERS. Add or update objects with your poster details: 

{
  id: "AA-001",
  title: "Your Submitted Poster Title Here",
  category: "Scientific Research",
  authors: "Dr. Author Name¹, Prof. Co-Author²",
  affiliations: "¹Institution A, ²Institution B",
  keywords: ["Mammography", "Biomarkers"],
  imageUrl: "assets/posters/AA-001.jpg",
  background: "Background & Objectives details...",
  methods: "Materials & Methods details...",
  results: "Study results and key metrics...",
  conclusion: "Conclusion details..."
}
